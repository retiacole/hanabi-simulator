# Hanabi Simulator

[ブラウザーで使う](https://retiacole.github.io/hanabi-simulator/)

OpenAI Codex（AI）を使って作成しました。

東京湾をイメージした2地点の花火を、距離・高度・周回位置・視線の角度を変えて観察する3Dシミュレーターです。標準速度で、燃え尽きた後の余韻を含む3分間。時刻バーと一時停止で同じ瞬間を別の方向から観察できます。

[index.html](./index.html) をブラウザーで開くと動きます。HTMLにすべてのコードを含み、外部ライブラリー・画像・通信は不要です。保存したHTMLだけでオフラインでも使えます。

## 観察できる花火

球形、輪形、しだれ、二重球、ヤシ、扇、土星、小花の群れ、金の大しだれ、彩色の光跡の10種類。種類を選ぶと、その形を観察しやすい時刻に移動できます。

煙の表示、濃さ（20〜500%）、風速（0〜12 m/s）、風の向きを変更できます。風は煙を表示していない場合も花火に作用します。風の向きは「吹いていく先」で、気象の風向とは逆です。

## 操作

| 操作 | キー・入力 |
| --- | --- |
| 上昇／下降 | ↑／↓、W／S |
| 中点の周囲を360°移動 | ←／→ |
| 近づく／離れる | A／Z、マウスホイール |
| 視線を上／下へ | E／D |
| 周回と視線を同時に変更 | 画面をドラッグ |
| 速く移動 | Shift＋移動キー |
| 再生／一時停止 | Space |
| 最初から再生 | R |
| 煙を表示／非表示 | H |

画面のボタンとスライダーでも操作できます。スライダーにフォーカスがある間は矢印キーでその値を変更します。別の場所へフォーカスを移すと視点操作に戻ります。

## モデルの範囲

打上玉・光る粒・尾の火花の三次元運動に重力と、風に対する速度の二乗に比例する空気抵抗を適用します。開花時の速度を次の粒へ引き継ぎ、小花の群れは子玉が飛んでから時間差で開きます。煙は計算された飛行・開花位置から生じ、移流・上昇・拡散によって薄くなります。

運動を物理法則に沿って計算していますが、実物の測定値で検証した再現ではありません。初速度・燃焼時間・色は仮定であり、燃焼化学、爆発圧力、複雑な乱流、散乱光は精密には解いていません。水面反射も見え方の近似です。2地点の間隔は460 mで、地形とプログラムは架空です。音・長時間露光機能はありません。

参考：[NASAの抗力式](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)、[日本煙火協会の花火解説](https://www.hanabi-jpa.jp/uchiage/structure.html)。

## 開発

`src/` のHTMLとJavaScriptから、配布用の単一HTMLを生成します。ビルドにはPython 3、数値モデルのテストにはNode.jsを使用します。追加パッケージは不要です。

```sh
python3 build.py
node tests/physics-check.cjs
node tests/smoke-physics-check.cjs
```

上記はリポジトリのルートから実行する例です。スクリプト内のパスはスクリプトの配置場所を基準にしているため、任意の作業ディレクトリーから実行できます。テストは運動の既知解・時間刻みの収束・速度の継承・風の作用・決定的な時刻移動・煙の拡散と濃さなどを確認します。テスト合格は実物との一致を保証するものではありません。
